# **App Name**: CrediKhaata

## Core Features:

- Add Customer: Simple form to add customer details: name, phone, address, credit limit, and a trust score.
- Record Credit Sales: Record credit sales with customerId, item description, loan amount, issue date, due date. Show active loans with status (pending, paid, overdue).
- Track Repayments: Record repayments (amount + date), auto-update balance on loan, track partial payments.

## Style Guidelines:

- Primary color: White or light grey for a clean interface.
- Secondary color: Dark blue or green for key actions.
- Accent: Gold (#FFD700) for highlighting important information.
- Mobile-first, one-handed design for ease of use.
- Simple, clear icons to represent actions and status.
